LSTM Architecture Details

  • Gates: Contains 3 gating mechanisms: Forget Gate (discards irrelevant past prices), Input Gate (updates candidate state), and Output Gate (controls cell output).
  • Internal State: Separates Cell State ($c_t$) from Hidden State ($h_t$), creating a constant error carousel that mitigates vanishing gradients over 60 time steps.
  • Parameters: 4 weight matrices per unit ($4 \times d$). Higher capacity, but slightly more susceptible to overfitting on noisy financial series.

GRU Architecture Details

  • Gates: Streamlined into 2 gating mechanisms: Reset Gate (controls how much previous memory to forget) and Update Gate (balances past and new candidate memory).
  • Internal State: Merges Cell State and Hidden State into a unified representation ($h_t$), allowing faster forward-backward passes and quicker convergence.
  • Parameters: 3 weight matrices per unit ($3 \times d$). Approximately 25% fewer parameters than LSTM, making it less prone to overfitting on stock volatility.
